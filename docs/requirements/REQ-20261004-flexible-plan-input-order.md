# 计划输入顺序自由

- 状态：confirmed，用户明确要求先选择时间再填执行次数。
- 目标：用户按自然顺序先选日期/时间/间隔，再填次数，不被表单锁住。
- 范围：次数为空、0 或暂时无效时，首次日期、时间、间隔、“现在”均保持可编辑；修改保留草稿。后续填有效正次数，序列使用先前设置预览。0 仍只执行额外唤醒。
- 校验：空白或无效次数不生成假序列、不视为已确认 0；保存时指出需填非负整数。未保存草稿与实际 Windows 计划状态保持区分。
- 边界：不改默认次数、调度语义、模型、路由或自动额度重置预填规则；不自动保存用户配置或更新 Windows 任务。
- 视觉/竞品：沿用已确认界面，无新增视觉设计或竞品参考。
- 验收：清空次数后可选择时间；0 后可选择时间及“现在”；输入 3 使用先前时间生成三次序列；暂时输入非法文字不锁字段；保存非法/空白次数有正确提示；0 加额外唤醒可正常生成计划。
- 执行：沿用 gpt-6-luna / max，小修订、单开发聊天串行、不使用子代理或桌面控制；代码与隐藏 WinForms 交互验证及 build/verify。
- 交付：固定 dist/CodexQuotaWaker.exe 与原启动器；占用时不强制结束、不创建新启动入口；按 fix 补丁版本处理。
