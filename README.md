# Codex 额度唤醒器

一个无需常驻的 Windows 小工具：按一次性有限序列或额外单次时间唤醒电脑，保持系统清醒，并通过 `codex exec --json` 发起一条可验证的本地 Codex 请求。

当前版本：`0.12.0`

## 使用方法

1. 双击 `dist\CodexQuotaWaker.exe`。
2. 设置统一计划：
   - 填写首次日期、时间、间隔和“序列执行次数（含首次，可为 0）”；需要从当前时间开始时可点击首次日期/时间旁的“现在”，它会设置为下一个整分钟。
   - 填写 `0` 时不生成序列，只执行“插入额外唤醒”中的时间；填写 `1` 时只执行首次时间；填写大于 `1` 时按间隔生成有限序列。
   - “插入额外唤醒”中的每个日期时间只执行一次；与序列重合的时间会自动去重。
3. 普通睡眠唤醒不需要后台运行选项；如需重启或注销后仍运行，勾选“重启或注销后仍运行”。点击保存时按 Windows 原生凭据窗口输入当前 Windows 帐户密码；开机 PIN、指纹和人脸不能代替账户密码。密码由 Windows 任务计划程序加密保管，本程序不会保存或记录密码。
4. 保持默认模型 `gpt-5.6-luna`，或选择其他当前可用模型。
5. 查看“请求链路测试”卡。“刷新配置”只读取当前 Codex / CC Switch 配置摘要；“测试请求链路”会沿当前配置发送一次真实请求，不会自动切换 provider、模型或路由。
6. 点击“测试请求链路”。成功后优先查看“链路已联通”和“最终模型”；最终模型只来自本次结构化响应或精确匹配的本地路由证据，无法识别时显示“未识别”。如果本次响应还提供唯一且可靠的额度重置时间，程序会把序列首次时间预填为本地时间的下一整分钟，并提示“尚未保存”。
7. 测试成功后点击“保存并启用”。取消凭据输入或注册失败时，原有计划不会被替换。
8. 到点运行后，重新打开程序查看最近结果；结果会展示本次实际链路、provider、最终模型、退出码和失败点。

程序会在请求和重试期间自动保持清醒，并按内部有限预算控制网络等待、请求超时和重试间隔；界面不再要求填写保持清醒时长。成功后是否睡眠仍由“任务唤醒电脑后，成功完成时自动睡眠”控制；它默认关闭。只有 Windows 明确记录本计划唤醒、有效请求成功且唤醒后无人操作时，才会显示 60 秒取消倒计时并请求普通睡眠；失败后交回 Windows 电源策略。

顶部“当前启用计划”会直接显示 Windows 中的实际状态、下次/最后一次触发时间及唤醒能力；下方时间线会列出正在执行的序列和插入的唤醒。修改计划后再次点击“更新并启用”，Windows 会覆盖更新下面这一条同名任务，不会增加第二条。

默认仅在用户登录 Windows 时运行；关闭“重启或注销后仍运行”时，Windows 更新重启后可能因没有登录会话而漏跑。普通睡眠唤醒不需要开启该选项。开启后，状态摘要会显示“无需登录也可运行”；再次更新该计划仍需重新输入当前 Windows 帐户密码。

窗口右侧可纵向滚动；“当前执行序列”和“最近一次结果”之间的横线可拖动，用来调整两个区域的高度。

程序会把稳定副本和运行数据保存到：

```text
%LOCALAPPDATA%\CodexQuotaWaker
```

Windows 计划任务名称：

```text
CodexQuotaWaker-Schedule
```

## 运行前提

- Windows 会话保持登录；锁屏、睡眠或休眠可以，注销后不保证执行。
- 当前电源方案和固件允许唤醒计时器。
- Codex CLI 已安装，并通过同一个 Windows 用户登录 ChatGPT。
- 如果使用 CC Switch 等本地代理，代理必须在唤醒后可用。

## 行为边界

- 只删除或修改名为 `CodexQuotaWaker-Schedule` 的 Windows 计划任务。
- 不操作 Codex 桌面 App 中已有的定时任务。
- 不读取或保存 ChatGPT Token、Cookie、密码或 API Key。
- 经过 CC Switch 时，只读取与本次请求时间精确匹配的非敏感请求目标行来识别实际上游和最终模型；日志不可用时显示上游未确认。
- 后台 Codex 请求使用 `read-only` 沙盒，并以有效模型响应和本地日志作为执行成功依据。
- 程序不读取或判断官方 Codex 额度桶、余额或重置时间。
- 自动睡眠只依赖有效请求成功、计划唤醒证据、唤醒后无人操作和 60 秒可取消倒计时等安全条件。
- 自动睡眠未勾选或安全条件不满足时，完成后交还原有电源策略。

## 构建与验证

项目使用 Windows 自带的 .NET Framework 4.8 编译器，无第三方依赖：

```powershell
.\scripts\build.ps1
.\scripts\verify.ps1
```

验证不会发送模型请求。它会临时注册一个惰性的测试计划任务，核对 `WakeToRun`、错过后运行和 EXE 路径后立即删除，不会改动正式计划或已有 Codex 任务。
